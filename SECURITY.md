# Security policy

harina stores personal financial data, so we take reports seriously.

## Reporting a vulnerability

Report vulnerabilities **only** through this repository's private vulnerability reporting: the **Security** tab, then **Report a vulnerability**. Please do not report them by email or in public issues, pull requests or discussions.

Include what you found, how to reproduce it, and the impact you expect. We will acknowledge the report, keep you updated, and credit you when the fix is published unless you prefer otherwise.

## Scope

The server and web app (`src/`, `public/`), the iOS app (`ios/`) and the hosted version at `harina.lzno.app`. Please do not access other people's data, degrade the service or run automated scans against the hosted version.

## Supported versions

Only the latest commit on `main` and the current TestFlight build.
